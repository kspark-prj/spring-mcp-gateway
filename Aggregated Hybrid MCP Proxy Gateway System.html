Aggregated Hybrid MCP Proxy Gateway System

로컬(STDIO) 및 원격(HTTP) MCP 서버를 단일 Streamable HTTP(`/mcp`) 엔드포인트로 통합 관리하고, 엔터프라이즈급 보안·안정성을 제공하는 고성능 하이브리드 프록시 게이트웨이 솔루션입니다.

📌 1. 도입 배경 및 핵심 가치

LLM 에이전트 환경에서 다양한 외부 툴(Tool) 연동을 위해 Model Context Protocol(MCP)이 확산되고 있으나, 프로토콜 파편화, 명칭 충돌, 보안 및 감사 로깅 부재의 한계가 존재합니다. 본 시스템은 이를 완벽히 해결합니다.

단일 접점 통일

오직 하나의 /mcp 엔드포인트를 통해 모든 로컬/원격 MCP 툴에 투명하게 접근합니다.

네임스페이스 라우팅

{server}__{tool} 규칙으로 서버 간 동일 툴 명칭 충돌을 원천 차단합니다.

인프라 경량화 & 자가치유

Redis 배제, Caffeine 로컬 캐시(Short TTL, Bounded Size) 적용으로 고성능 및 인프라 비용 최소화.

⚡ 2. 엔터프라이즈 핵심 기술 명세

01

Java 21 Virtual Threads I/O 격리

STDIO 프로세스의 블로킹 I/O 작업을 전용 Virtual Thread로 완전히 격리하여 Reactor 이벤트 루프 보호.

02

Netty DataBuffer 파이프라인 (Zero-Leak)

10MB 페이로드 조기 차단으로 DoS/OOM 방어 및 스트리밍 무지연 중계 보장.

03

지능형 Watchdog & 자가 재시작

STDIO 비정상 크래시 감지 시 지수 백오프(Exponential Backoff) 기반 자동 재시작 수행.

04

SSRF 원천 차단 & 보안 인증

AWS/GCP 메타데이터 및 사설 IP 대역 접근 통제, SHA-256 API Key 핑거프린트 인증.

05

동적 PII 및 강제 비밀값 마스킹

개인정보 동적 마스킹 외에도 인증 토큰·비밀값은 설정과 무관하게 전역 영구 마스킹 처리.

06

35초 Drain Timeout (Graceful Shutdown)

배포/스케일인 시 LLM 에이전트의 인플라이트 툴 실행 요청을 안전하게 완수 후 종료.

🖥️ 3. 윈도우 환경 STDIO 통신 서버 등록 예제

관리자 대시보드(/dashboard.html) 또는 API를 통해 로컬 STDIO 서버를 등록할 때 아래와 같이 설정합니다. 예를 들어 윈도우 파일시스템 서버를 연동하는 명령어 예시는 다음과 같습니다:

# Windows 환경 파일시스템 STDIO 업스트림 등록 예시 명령어
npx -y @modelcontextprotocol/server-filesystem C:\Users\username\Downloads
💡
팁: 게이트웨이는 내부적으로 Virtual Thread 기반의 `ProcessBuilder`를 통해 해당 명령어를 구동하고, 표준 입출력(`stdin`/`stdout`)을 프록시하여 단일 /mcp 엔드포인트로 통합 중계합니다.
